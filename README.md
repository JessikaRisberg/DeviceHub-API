# DeviceHub-API

DeviceHub API is a RESTful backend for managing IoT devices, users and sensor data. 


Technologies
Runtime - Node.js 22 LTS
Language - TypeScript
Framework - Express
Database - PostgreSQL
ORM - Prisma
Authentication - JWT
Validation -Zod
Tests - Vitest
API-documention - Swagger/OpenAPI
Code quality - ESLint + Prettier
Container - Docker
